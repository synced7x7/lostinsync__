# Roadmap

Implemented in the first native milestone: Tauri 2 shell, SQLite persistence, versioned schema migration, add/update game flow, manual sessions, timestamp-based playtime, and browser fallback storage.

Not implemented yet: full route navigation, cover import, journal/profile/activity pages, backups, import/export, automatic Windows process detection, and the Android/React Native client.

Status transitions, automatic tracking permissions, launcher matching, sleep/resume handling, and session correction should be specified before those features ship.
